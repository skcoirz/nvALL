Welcome to nvALL — a fast, lightweight note-taking app for macOS.

Your notes are plain text files (Markdown, TXT, or RTF) stored in a folder on your Mac. No cloud, no database, no lock-in. You own your data.

Getting Started
  - Type in the search bar to find notes instantly
  - Press Enter to select the top match, or create a new note if nothing matches
  - Press Cmd+N to create a new note
  - Notes auto-save as you type

Keyboard Shortcuts
  - Cmd+L: Focus the search bar
  - Esc (1x): Focus search bar
  - Esc (2x): Clear search text
  - Esc (3x): Deselect note and clear editor
  - Up/Down arrows: Navigate notes from search bar
  - Cmd+F: Find within a note
  - Cmd+N: New note
  - Cmd+,: Preferences
  - Tab: Inserts 2 spaces

Layout
  The app has three areas stacked vertically:
  1. Search bar — search and create notes
  2. Notes list — shows all notes with title, preview, and date
  3. Editor — view and edit the selected note

Drag the divider between the list and editor to resize them.
