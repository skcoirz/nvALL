nvALL search works across both note titles and content.

How Search Works
  - Type in the search bar to filter notes
  - Notes are ranked by relevance: exact title match > title prefix > title contains > content matches
  - All notes stay visible — matching notes sort to the top, non-matching ones appear below
  - Search is case-insensitive

Navigating with the Keyboard
  - Use Up/Down arrow keys while in the search bar to move through the list
  - Press Enter to select the top match
  - If no match exists, Enter creates a new note with the search text as its title

Search Highlighting
  - When you search, matching terms are highlighted in yellow in the editor
  - Orange marks appear on the scrollbar showing where matches are in long documents
  - Highlights update as you navigate between notes

Tips
  - Search for a word you remember to quickly find a note
  - Use multi-word searches — each word is matched independently
  - Clear the search (Esc) to see all notes sorted by last modified date
